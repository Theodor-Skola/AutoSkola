# Autoschool
Simple docker compose with nginx, apache and c# backend for school project

## About
A project done for our web development and econ course. It uses an apache http server for serving static content, an backend written through C# for api calls and nginx to route through the docker


### api
The api is just a simple restful api, which is written using the webapi dotnet template. It gets messages sent through one of the webpages and saves it to a csv file.
